## 📖 About

**MERN Mastery** is a full-stack learning platform that guides you through the entire MERN stack — from HTML/CSS/JavaScript basics to React, Node.js, Express, and MongoDB.

It combines structured courses, progress tracking, interview Q&A, and code practice into one clean dashboard.

> 💡 *Small steps every day lead to big results.*

---

## ✨ Features

- 🏠 **Dashboard** — Learning stats, live code card, and progress tracker
- 📚 **7 Courses** — HTML, CSS, JavaScript, React, Node.js & Express, Express.js, MongoDB
- ✅ **Progress Tracking** — Per-course lesson completion & overall %
- 🎯 **Interview Q&A** — Technical interview preparation
- 💻 **Code Practice** — Hands-on coding area
- 🔍 **Course Search** — Quickly find any course
- 🗺️ **MERN Roadmap** — See how the stack connects: React → Node.js → Express → MongoDB
- 📱 **Responsive Design** — Works on all devices

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (local or Atlas)
- npm

### Installation

```bash
# Clone the repo
git clone https://github.com/<your-username>/mern-mastery.git
cd mern-mastery

# Install backend
cd server
npm install

# Install frontend
cd ../client
npm install
